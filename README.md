# Neural Networks & Deep Learning – QNN vs Classical NN

This project compares a Classical Neural Network (CNN) and a Quantum Neural Network (QNN) for phishing website detection using machine learning and quantum computing techniques.

The notebook includes:
- Data preprocessing and feature selection
- Classical neural network implementation with TensorFlow/Keras
- Quantum neural network implementation using PennyLane
- Model training and evaluation
- Accuracy and loss analysis
- Performance comparison between classical AI and QNN models

## Technologies Used
- Python
- TensorFlow / Keras
- PennyLane
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
